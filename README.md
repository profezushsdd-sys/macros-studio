# macros-studio

Página de prueba interactiva de Macro Studio para Windows.

La demo simula la edición y reproducción de acciones dentro del navegador; no controla el equipo del visitante. El sitio utiliza `index.html`, `Video Project 3.mp4`, `Demo_Macro_Studio.mp4` y `Designer (16).png`.
